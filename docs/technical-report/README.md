# Technical report

The Open-VC Attention technical report, in two formats:

- [`report.en.md`](report.en.md): Markdown, readable on GitHub, with its figures in [`figures/`](figures/).
- [`Open-VC-Attention-Technical-Report.pdf`](Open-VC-Attention-Technical-Report.pdf): the typeset PDF.

The measurements behind its numbers are the benchmark records in [`benchmarks/results/b200/`](../../benchmarks/results/b200/); keep both formats consistent with those records and with each other when anything changes.
